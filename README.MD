## 📁 Estrutura do Projeto

```
blogandre/
├── src/
│   ├── js/
│   │   └── animation.js   
│   └── css/
│       └── style.css     
├── index.html         
├── tailwind.js 
├── README.md
└── LICENSE
```

Como este é um projeto front-end simples, basta abrir o arquivo `index.html` no navegador:

```bash
# Clone o repositório
git clone <url-do-repositorio>

# Entre na pasta
cd blogandre

# Abra o index.html no navegador
```
